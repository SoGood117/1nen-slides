ルールやり方例
① ふつうそのまま ＋edwalk → walked
② e で終わる＋d だけuse → used
③ 子音＋yy を i にして edstudy → studied

⚠ 母音＋y はそのまま ed！　play → played（✕ plaied）

⑥ 並べかえ

日本語に合う英文をつくろう

1あなたは昨日、自転車のカギをなくしました。
( your bicycle key / you / yesterday / lost )
→ You lost your bicycle key yesterday.主語→動詞(過去)→目的語→時。lose の過去は lost
2タロウは数学を一生懸命勉強しました。
( hard / math / studied / Taro / very )
→ Taro studied math very hard.様子の副詞 very hard は文のうしろ
3僕たちは先週、クリスマスパーティーをしました。
( a Christmas party / last / had / we / week )
→ We had a Christmas party last week.have の過去は had。last week は文末
4彼女は今朝、黒ネコを見ました。
( a black cat / she / morning / saw / this )
→ She saw a black cat this morning.see の過去は saw。this morning は文末
5僕は去年100冊の本を読みました。
( books / I / hundred / last / one / read / year )
→ I read one hundred books last year.one hundred ＝100。read は形そのまま（過去）

⑦ のまえに

過去か現在かは「目印のことば」で決まる

過去の目印 → 過去形
yesterday ／ last 〜
the day before yesterday（おととい）
〜 ago ／ then（そのとき）
現在の目印 → 現在形
now（今）
every day（毎日）
これからの tomorrow も動詞は現在形のまま
⚠ 1つの文でも 前半は過去・後半は現在など、目印ごとに時制を切りかえる！

⑦ 過去か現在か（1〜4）

○で囲むのはどれ？

1Takeshi ( plays / played ) tennis last Sunday.
→ playedlast Sunday ＝過去
2The baby ( cries / cried ) last night.
→ criedlast night ＝過去。cry → cried（子音＋y）
3I ( want / wanted ) to go to a movie tomorrow.
→ wanttomorrow は未来 → 動詞は現在形のまま。ひっかけ！
4A police officer ( stops / stopped ) my car yesterday. I ( am / was ) very surprised then.
→ stopped ／ wasyesterday・then ＝過去。両方とも過去形

○で囲むのはどれ？

5My sister ( has / had ) a cold last week. She ( is / was ) OK now.
→ had ／ islast week＝過去 had ／ now＝現在 is。目印でスイッチ！
6Yuka ( studies / studied ) history at university and she ( becomes / became ) a history teacher last April. She ( teaches / taught ) history at a high school now.
→ studied ／ became ／ teacheslast April＝過去（studied・became）／ now＝現在（teaches）
